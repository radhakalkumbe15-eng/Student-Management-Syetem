Student Management System
A console-based Student Management System built using Java,MySQL,and JDBC. The project allows user to manage student records through a simple menu-driven application.

Features
-Add a new Student -View All Students -Search Student by ID -Update Student details -Delete Student -store student data in MySQL database -Input Validation for student details

Technologies Used
-Java -JDBC -MySQL -VS Code -Git and GitHub

Database
The application uses MySQL to store student information such as: *Student ID *Name *Email *Phone *Course *Semester *Marks

Project Structure
StudentManagement/ |__src/ | |__Main.java | |__Student.java | |__studentDAO.java | |DBConnection.java | |.gitignore |____README.md

How to Run
1.Install Java JDK. 2.Install MySQL. 3.Create the required database and student table. 4.Update the database username and password inDBConnection.java. 5.Add MySQL connector/J JDBC driver. 6.Complie and run Main.java. 7.Use the menu displayed in the terminal to manage student records.

CRUD Operations
Create-->Add Student Read-->View/Serach Student Update-->Update student Delete-->Delete student
